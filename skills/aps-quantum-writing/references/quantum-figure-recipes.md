# Quantum figure recipes: select the evidence route, not a visual template

Use this reference for quantum-physics figure planning after identifying the supported claim. It routes to relevant domain guidance within FIGURES; it is not a fourth top-level branch. Each recipe specifies a question, observables, discriminating controls and interpretation limits. It is neither an instruction to perform unrequested research nor a mandatory figure/panel sequence.

Start with the [fixed figure record](figure-planning-record.md). Choose only the recipe(s) that match the actual scientific task; a platform name alone is insufficient. Assign flexible roles to the evidence actually available. Missing mechanism evidence remains missing; statistical error bars, phase maps and visual complexity cannot substitute for it. An analytical paper can use equations, a proof diagram or a table and need no data figure.

| Logical protection, decoder/recovery, postselection or a heralded protocol | [Quantum information](quantum-figures-information.md) |
| Algorithm, compilation, resource bound or certification claim | [Quantum information](quantum-figures-information.md) |
| Identifiable noise/channel model or operational sensing/network resource | [Quantum information](quantum-figures-information.md) |
| Hardware control/readout, measurement precision, photonic interface or learned quantum workflow | [Devices and learning](quantum-figures-devices.md) |

A paper can combine routes: a learned decoder needs the logical-cost route and the learning-split route; a heralded photonic device needs conditional quality and useful output rate. Combine their shared records rather than duplicate figures.

## A recipe changes the decision, not just the plot label

For the selected task, record:

- Which competing interpretation the proposed observable can actually distinguish.
- Which condition, denominator, ensemble or resource convention changes the inference.
- Which comparison or control is essential and which is merely optional supporting evidence.
- Which uncertainty/convergence checks belong to data, model, estimator and finite-size limits.
- Which failure or counterexample would require narrowing the claim.

Only then choose the plot geometry. A mean curve, map, spectrum, distribution, schematic or table is selected by its evidential job, not by a quota of diverse chart types. Keep core conditions and necessary negative controls visible. Do not append an unrelated limitation panel just to fill a role.

## Column choice and evidence status

Begin single-column unless the user specified otherwise. Test mechanism/comparison integrity, final-size legibility and scientific geometry before choosing double column, following the [column decision](figure-planning-record.md#single-column-first-with-an-explicit-escape-test). Several published cases inspected in this reread show many panels in one column and fewer in two; this establishes counterexamples to a panel-count rule, not a universal optimum or a survey of APS preferences.

The source links in these routes point to original review observations and exact versions. The [review record](../evidence/quantum-figure-review/README.md) distinguishes metadata screening, clipped excerpt screening, substantive targeted inference-chain review, complete main-text review and actual pixel inspection. Source version and reading scope matter: an author manuscript can support scientific relationships without proving final journal typography. Source count is not evidence that these instructions improve model output or journal acceptance.
