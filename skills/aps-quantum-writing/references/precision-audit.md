# Audit Precision Where a Specific Problem Requires It

Use this reference only when the user requests an itemized audit or the manuscript contains a specific scientific contradiction or ambiguity. Routine revision checks need not become a visible checklist.

First locate the problematic claim and its evidence. Identify where the meaning changes: the object, quantifier, model, metric, baseline, uncertainty, cost, or evidence level. Preserve what is valid in the manuscript and correct the specific shift. If the issue cannot be resolved, ask the author one concrete question.

| Trigger | Distinctions to check |
|---|---|
| Algorithmic/QML advantage | Input access model; precision; queries, gates, or time; preparation and readout; the same task and budget; a gap between upper bounds versus a proven separation |
| Open-system approximation | System–bath assumptions, perturbation order, timescales, and initial correlations; exactness within the model versus physical validity |
| Fidelity/correlations/metrology | Conditional versus unconditional; a single trajectory versus an ensemble; a witness versus a quantitative measure; QFI versus implementable readout; uncertainty definitions |
| Numerical limits | Size, time, geometry, truncation, and convergence; observation, extrapolation, conjecture, and proof |
| Undefined symbols or unclear exposition | First definitions, dimensions, indices, and quantifiers; separately check proof exposition order and actual logical dependencies; accurate, noncircular forward references |
| Text–figure disagreement | Quantities, units, normalization, experiment versus simulation, corrections, parameters, and curve identities |

For a sentence deletion, ask whether the remaining paragraph still makes the same scientific judgment. Delete wording that removes only authorial posture or local repetition. If a necessary assumption, genuine negative result, or comparison disappears, restore its scientific content beside the relevant claim. If an inference lacks proof, delimit the claim through the established evidence type and domain rather than inserting “the authors have not proved” into the manuscript. Judge negation and uncertainty by their meaning, not by a banned-word list.

Organize the audit output as requested. Usually provide revised text and list only contradictions affecting the conclusion, the repairs made, and questions requiring additional evidence. There is no need to demonstrate that the editing was cautious. Source cases are recorded in the [evidence ledger](evidence-ledger.md); consult it when tracing provenance is necessary.
