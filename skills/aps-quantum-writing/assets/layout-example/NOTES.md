# Compiled layout demonstration

layout.tex compiled with APS official REVTeX 4.2f and pdfTeX; layout.pdf and page PNGs were visually inspected. It demonstrates a single-column figure on page 1 and a figure* at page 2 top. It is deliberately short, leaving whitespace; this is not a full scientific manuscript or a page-budget model. Two underfull text-line warnings remain, with no overfull boxes or missing references.

On a standard TeX installation containing REVTeX, compile from this directory with pdflatex layout.tex twice. This run used scratch-local format/font-map recovery and official class files; no global or user-computer installation was made. Figure paths are relative to the preserved skill directory.
