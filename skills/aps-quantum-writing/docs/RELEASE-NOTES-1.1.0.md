APS Quantum Writing 1.1.0 adds a dedicated abstract-writing reference within the existing WRITING and PLANNING branches. It connects the core contribution, indispensable method, and warranted reasoning, with seven journal profiles and explicit evidence boundaries. Technical abstracts, Popular Summaries, and suitability statements remain distinct.

The supplied revision-3 supplement contributes a 29-abstract review ledger and 16 editorial acceptance scenarios. These are attributed source material, not a newly executed 16-case benchmark or a reread of the full 700-paper corpus. Selected official abstract requirements were rechecked during integration; the PRL character-limit conflict remains documented.

This release also includes the independent 2026-10-20 REVTeX 4.2f revalidation of five public heading examples: two compilation passes per example, 120 new PDF/log checks, full-page visual review, and a clean replay. The historical 29-source/32-assertion matrix is still inherited and separate. TeX source and helpers are unchanged.

Download `aps-quantum-writing-1.1.0.zip` for installation. The source ZIP is for repository development. `SHA256SUMS` covers both archives, the original heading preview, and the public revalidation evidence bundle. The public evidence export replaces local paths in text logs with placeholders.

Automated tests, archive checks, and validation limits are documented in `docs/RELEASE-1.1.0.md` inside the package. License terms are unchanged: noncommercial source-available use, with the existing research-output and third-party exceptions. This is an independent project, not an APS-endorsed template.
