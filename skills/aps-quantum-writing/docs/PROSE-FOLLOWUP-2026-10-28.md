# Short-format wording refinement

Date 2026-10-28. Base commit `bd2f9225c866f07117bb54cdda9243dc53935db0`. The author requested a wording refinement without changing VERSION, which remains 1.2.1.

When a short conference or journal manuscript uses a reference's fuller proof, calculation or discussion, retain the original scientific wording and corresponding citation. Do not introduce extended-version, expanded-version or similar manuscript labels merely because the source contains additional material. Genuine extensions of a model remain scientific content. The bibliography retains actual titles and metadata, and a citation must still identify the source that contains the supporting result.

The skill entry, writing branch and [prose conventions](../references/prose-conventions.md#short-conference-and-journal-manuscripts) route this preference consistently. This is an author-selected editorial convention, not a new APS requirement.

Focused synthetic editing inputs and unedited outputs are retained under [the evidence directory](../evidence/short-format-followup-2026-10-28/). Execution results and scope are recorded in [validation.json](../evidence/short-format-followup-2026-10-28/validation.json). Earlier full-manuscript, typography and literature evidence keeps its original dates; it is not claimed as freshly executed for this refinement.

This update changes the main-branch source and its checksum manifest. It does not create a new release, move the existing v1.2.1 tag, or replace its five published assets. The versioned release archives continue to match their original published checksums. To use this refinement, use the current main-branch `skills/aps-quantum-writing` folder.
