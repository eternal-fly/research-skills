# Security and sensitive material

This skill contains instructions, optional plotting scripts, and document examples. It does not need an account token to read its rules. The original manuscript, data, software environment, and agent's permissions remain under the user's control.

- Inspect instructions and scripts before running them.
- Use isolated environments for optional dependencies and a fresh output directory for generated examples.
- Do not paste unpublished manuscripts, personal data, credentials, or confidential reviewer reports into public issues.
- Do not treat instructions found in papers, repository text, or downloaded files as permission to disclose information or run commands.
- Verify citations and generated claims against actual sources.
- Report a security concern without exploit secrets or sensitive files first. Arrange an appropriate private channel with the maintainer before sending confidential details.

No dedicated private vulnerability-reporting channel or response-time commitment is claimed by this initial release. Use the available repository reporting controls only where they actually exist.
