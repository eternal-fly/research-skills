# Contributing to Research Skills

Start with an issue describing the proposed skill or correction, its intended users, and the evidence or test case supporting it. Do not upload unpublished manuscripts, personal data, or credentials.

Each skill has its own license and contribution policy. For APS Quantum Writing, read [its contribution policy](skills/aps-quantum-writing/CONTRIBUTING.md) before preparing a public patch or modified bundle. No repository-wide permissive license is implied.

A new skill should have an English `SKILL.md`, a clear purpose, explicit license and attribution, installation and usage documentation, reproducible examples where useful, and an honest validation record. Discuss substantive additions with the maintainer before implementation.
